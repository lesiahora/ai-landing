# AI Landing Page with Vite

Современный landing page, построенный на **Vite** — быстром инструменте для разработки.

## 🚀 Структура проекта

```
├── index.html          # Главный файл HTML
├── package.json        # Конфигурация проекта
├── vite.config.js     # Конфигурация Vite
├── src/
│   ├── main.js        # Точка входа JavaScript
│   └── style.css      # Стили
└── dist/              # Результат для продакшена (генерируется автоматически)
```

## 📦 Установка зависимостей

```bash
npm install
```

## 🎯 Команды

### Разработка (Hot Module Replacement)
```bash
npm run dev
```
Запустит локальный сервер на `http://localhost:5173` с автоматической перезагрузкой.

### Сборка для продакшена
```bash
npm run build
```
Создаст оптимизированную версию в папке `dist/`.

### Просмотр сборки
```bash
npm run preview
```
Предпросмотр результата сборки локально.

## 🎨 Особенности

- ⚡ **Молниеносная разработка** благодаря Vite
- 🎭 **Красивый UI** с градиентами и анимациями
- 📱 **Адаптивный дизайн** для всех устройств
- 🔄 **Hot Reload** при сохранении файлов
- 📦 **Оптимизированная сборка** для продакшена

## 💡 Что дальше?

1. Запустите `npm run dev` для начала разработки
2. Отредактируйте файлы в `src/` 
3. Используйте `npm run build` для финальной сборки
